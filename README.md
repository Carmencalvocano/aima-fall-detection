# AIMA Fall Detection

Proyecto para detección de caídas con backend y frontend.

## Estructura

- `backend/` - API y lógica de servicios
- `frontend/` - interfaz de usuario
- `docs/` - documentación del proyecto

## Requisitos

- Python
- Node.js
- npm o pnpm

## Inicio rápido

1. Instala las dependencias del backend.
2. Instala las dependencias del frontend.
3. Ejecuta ambos servicios.
